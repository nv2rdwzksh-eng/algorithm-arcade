# Algorithm Arcade

## Platform

Web, local Vite project.

## Stack

Vue 3, TypeScript, Vite, SVG and CSS, Vitest, Playwright. No UI or state libraries.

## Product Purpose

Visualize classical algorithms through deterministic typed execution events and reversible playback.

## Capabilities and Constraints

First approved slice: Bubble Sort and shift/write Insertion Sort, adjustable array size, randomization, playback controls, comparisons/swaps/writes/step statistics. Pure algorithms must not import Vue or mutate inputs. Pathfinding and dynamic programming are future modules.

## Users

Assumption: people learning algorithms through step-by-step exploration. Specific audience remains open.

## Brand Commitments

Algorithm Arcade. No supplied visual assets or fixed brand palette.
